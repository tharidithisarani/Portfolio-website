## Hosting

## Getting Started

To run locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Tharidi2002/Portfolio-website.git
   cd Portfolio-website
   ```
2. Install dependencies (if applicable):
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Visit `localhost:3000` (or the specified port).
